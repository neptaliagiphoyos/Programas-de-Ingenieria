# Plantilla 4D Integrado · versión de demostración

Herramienta de gestión de obra en un solo archivo, que funciona sin internet:

- **Inicio**: datos clave de la obra.
- **Presupuesto**: capítulos, partidas y cronograma financiero.
- **Planos y 3D**: modelo 3D, láminas y superposición de planos.
- **Costo - Cronograma**: simulador de costos y plazo.
- **Control de obra**: curva S, SPI, CPI y valorizaciones.
- **Simulador 4D**: la obra se arma día a día según el cronograma.
- **Pretratamiento**: simulador de la planta de pretratamiento.

Esta demostración trae un edificio de ejemplo con **datos ficticios**. Se pueden recorrer todos los módulos y probar cambios en pantalla.

Estas funciones solo están en la **versión completa**:

- cargar un proyecto propio;
- guardar escenarios;
- exportar a Excel o a imagen.

Para verla, abra `index.html` en el navegador, o use el enlace de GitHub Pages de este repositorio.
