# Ventanas Ordenadas para Windows

Un clic abre y acomoda tus aplicaciones de trabajo en la pantalla (o pantallas) que elijas, y cada escritorio virtual de Windows tiene su propia lista de apps y su propio acomodo.

**Descarga:** [VentanasOrdenadas.zip](VentanasOrdenadas.zip) (o el archivo [VentanasOrdenadas.hta](VentanasOrdenadas.hta)). Es un solo archivo, no necesita instalación ni internet.

## Qué hace
- **Abrir todo:** abre solo lo que aún no está abierto, en el escritorio de Windows que elijas, y lo acomoda.
- **Solo acomodar** y **Cerrar todo** de las apps de la lista.
- **Escritorio:** lista desplegable con tus escritorios de Windows; cada uno guarda su lista de apps y su diseño.
- **Diseñar vistas:** recuadros que se arrastran y se estiran, con auto-calce para no dejar huecos entre ventanas ni con los bordes. Detecta los monitores de la PC y guarda el diseño en proporciones, así que se adapta a cualquier resolución.
- **Agregar** webs (Edge/Chrome, con modo aplicación sin barra de pestañas y zoom 90 %), programas y apps de Windows.

## Uso
1. Descomprime el zip y haz doble clic en `VentanasOrdenadas.hta`.
2. Si Windows avisa que el archivo vino de internet: Propiedades → «Desbloquear».
3. Elige el escritorio, agrega tus apps y pulsa **Diseñar vistas** para acomodarlas.

Requiere Windows 10/11. La configuración se guarda en la PC (registro de Windows, `HKCU\Software\AbrirTrabajo`).
